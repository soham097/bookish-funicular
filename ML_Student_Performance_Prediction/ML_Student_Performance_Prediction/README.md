# Student Performance Prediction Using Machine Learning

A reproducible machine-learning mini project for classifying a student's academic performance into **Needs Support**, **Developing**, or **High Performer**.

> **Dataset note:** The bundled data is synthetic. It is generated by `main.py` with a fixed random seed so the project can run offline and does not contain real student records. The model is an academic demonstration, not a validated assessment tool for real student decisions.

## Setup and execution

Use Python 3.10 or later. From this directory, run:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

`main.py` regenerates the synthetic dataset, compares four classification algorithms using 5-fold stratified cross-validation, selects the model with the highest mean cross-validation macro F1, evaluates it on a held-out 25% test set, and saves the model, metrics, charts and a sample input.

To run a sample prediction:

```bash
python predict.py --input outputs/sample_input.csv
```

To predict from your own file, provide a CSV containing these 12 columns:

```text
weekly_study_hours, attendance_percent, previous_exam_score,
assignment_average, quiz_average, sleep_hours, class_participation,
parental_support_level, tutoring, internet_access,
extracurricular_activity, travel_time_minutes
```

Example:

```bash
python predict.py --input my_students.csv --output my_predictions.csv
```

Binary fields use `0` or `1`. The `parental_support_level` field ranges from 1 (low) to 5 (high), and `class_participation` ranges from 1 to 10.

## Dataset and target

The generated data contains 1,500 rows. Inputs describe study habits, attendance, previous exam performance, assignment and quiz averages, sleep, participation, support, tutoring, internet access, extracurricular activity and travel time.

`final_score` is generated for each synthetic record and converted to a target class:

- **Needs Support:** final score below 60
- **Developing:** final score from 60 to below 75
- **High Performer:** final score of 75 or above

`final_score` and `performance_level` are excluded from model inputs. This avoids direct target leakage. The data generation process is available in `main.py`.

## Models compared

- Logistic Regression
- Random Forest
- Extra Trees
- Gradient Boosting

The evaluation reports accuracy, weighted precision and recall, macro F1, a confusion matrix, per-class metrics and permutation feature importance. Macro F1 is used for model selection because it gives each class equal weight.

## Results from the bundled run

The bundled run selects **Logistic Regression** using 5-fold cross-validation macro F1. The held-out test accuracy is approximately **76.27%** and test macro F1 is approximately **0.756**. Exact values are in `outputs/metrics.json`.

These metrics describe only this generated dataset and fixed random split. They should not be interpreted as expected performance on real students.

## Ethical and practical limitations

- Synthetic relationships do not represent all real learning environments.
- The generated feature weights and thresholds are assumptions for teaching purposes.
- Real student decisions should not be automated using this project.
- A real deployment would require consent, privacy controls, representative data, bias and fairness audits, validation across schools, and educator oversight.
